ForgeFIRM

    Let's set up your machine

    ForgeFIRM is on this machine. Before it cuts anything, it asks you to read a few things, set up your account, and tell it what it needs to know about the machine.

    What this takes

    About fifteen minutes for this part. You can stop at any step and come back; your progress is saved on the machine.

    Machine… Firmware…

    Read these first

    Four short documents. Read each one to the end, then confirm it. The safety document asks you to type a phrase. When all four are confirmed, the machine asks for one press of its button.

    Press the button on the machine

    The button on the machine is breathing teal. One press is your acceptance of the four documents, made at the machine, by you.

    Waiting for your press…

    Your account

    The name and password for this control panel. The same name and password open the machine's shell over SSH, which stays off until you turn it on from the panel.

    Lowercase letters, digits, "-" and "_". Two to 32 characters.
    At least eight characters. A few words you can remember work well.

    If you forget the password: hold the machine's button while you turn the machine on, for ten seconds, until it blinks amber. The setup then asks for a new one.

    Preferences

    A few choices that shape what the panel shows and how the radio behaves.

    A display preference. The machine stores everything in metric.
    Sets the channels and power the radio is allowed to use where you are. Automatic follows the access point.

    Which model is it?

    The label is on the back of the machine, near the power inlet.

    Sheet id

    …
    This code identifies your machine on the commissioning sheet it will burn later. It is made from the serial number with a secret kept on the machine, so it does not reveal the serial number. You can share a photo of the sheet.

    Cloud mode

    Cloud mode connects the machine to the Glowforge service as itself, with its software named as ForgeFIRM, and uses the service the way a stock Glowforge does, so the Glowforge app works as it did. It is off by default, and everything else works without it.

    Before you turn it on

    You read the cloud service document. In short: it is up to you to stay within the terms of your Glowforge account; Glowforge may refuse or block a machine that runs software it did not make, and this project cannot prevent or reverse that; the identity in the machine's fuses cannot be changed or replaced.

    Type I UNDERSTAND to confirm:
    The one thing in GRBL mode that reaches the service: a homing cycle that finds the head with the cameras. Without it the machine cuts from wherever the head is.
    Identity override (rarely needed)
    Only for a board whose fuses cannot be read. Leave both blank otherwise.
